家庭雙寶理財管理網站

使用方式：
1. 解壓縮 ZIP。
2. 將 index.html 上傳至 GitHub repository 根目錄。
3. 到 Settings > Pages，選擇 Deploy from a branch、main、/(root)，儲存。
4. 開啟 GitHub Pages 網址即可使用。

預設設定：
- ZOEY、PEGGY 每人每月零用錢 NT$1,500
- 每月 1 日領取，每月最後一天結算
- 預設每位孩子：儲蓄 35%（$525）、目標基金 35%（$525）、日常消費 30%（$450）
- 「設定」頁面可分別設定 ZOEY、PEGGY 的帳戶比例；儲蓄與目標基金比例相同，兩者加上日常消費比例後須合計 100%。

資料儲存於使用者目前瀏覽器的 localStorage，不會自動同步不同裝置或不同瀏覽器。建議定期備份瀏覽器資料或另行匯出紀錄。
